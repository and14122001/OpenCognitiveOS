# OpenCognitiveOS
Local-first adaptive multi-model cognitive operating system


## 繁體中文 / Traditional Chinese

[完整 v8.4 架構、研究參考與開發路線](README.zh-TW.md) | [AI Agent 開發規範](AGENTS.md)

Local-first adaptive cognitive system: Hermes, deterministic governance, optional authorized cloud model providers, federated world models and independent verification. Research/prototype stage; integrations not yet validated.

The [integration evidence matrix](docs/ACCEPTANCE_MATRIX.md) records native Linux proof, pinned local agent and model runs, portable regression logs, cross-host restoration and open acceptance criteria. The [CPU experiment archive](docs/validation/ab/README.md) includes preregistrations, measured resource use and replayable raw outputs.
